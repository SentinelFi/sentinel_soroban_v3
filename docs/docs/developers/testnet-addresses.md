# Testnet Addresses

The canonical record is [`deployments/testnet.json`](https://github.com/SentinelFi/sentinel_soroban_v3/blob/main/deployments/testnet.json).

## Parameters

Amounts use 7 decimals (10,000,000 = 1 USDC).

| Parameter | Value | Meaning |
|---|---|---|
| Default premium | 500000000 | 50 USDC |
| Default payoff | 5000000000 | 500 USDC |
| Default delay threshold | 3 | hours |
| Minimum lead time | 3600 | 1 hour before departure |
| Claim expiry window | 5184000 | 60 days |
| Minimum withdrawal request | 1000000000 | 100 USDC |
| Solvency ratio | 100 | 100 percent, fully backed |
