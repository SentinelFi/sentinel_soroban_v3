# Sentinel Documentation

Documentation site for the Sentinel protocol, built with [Docusaurus](https://docusaurus.io/).

## Local development (optional)

```bash
cd docs
npm install
npm start        # dev server at http://localhost:3000
npm run build    # production build into docs/build
```

Local install is not required to publish. Every push to `main` that touches `docs/` is built and deployed by the `Deploy Docs` GitHub Actions workflow.

See [DEPLOYMENT.md](./DEPLOYMENT.md) for GitHub Pages setup and custom domain instructions.
