# Contributing

Contributions are welcome!

## Getting started

1. **Open an issue first**: Start by [opening an issue](https://github.com/SentinelFi/sentinel_soroban_v3/issues/new) to discuss your idea and align on the change before you write code.
2. **Or open a PR directly**: If no clarification is needed and the fix is straightforward, feel free to fork the repository and open a pull request right away.

## Before you submit

- **Run the tests** and make sure they pass.
- **Make sure the project builds.**
- **Document your changes** where it matters — update comments, docs, or the relevant files.
- **Request a review** when your pull request is ready.

## Questions and suggestions

Want to ask something, suggest an idea, or clarify anything? [Open a new issue](https://github.com/SentinelFi/sentinel_soroban_v3/issues/new) — we're happy to help.

Thank you for contributing!
